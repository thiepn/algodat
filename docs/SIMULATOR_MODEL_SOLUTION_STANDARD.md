# Standard für Modelllösungen

Jede Klausuraufgabe verwendet die kanonische, deterministische Trainerlösung. Sie wird erst nach Abgabe als beschriftete Antwortstruktur dargestellt; Roh-JSON, interne Adapter-IDs und versteckte Musterlösungen werden nicht angezeigt.

Die Darstellung enthält je nach Familie Tabelle, Zustandsfolge, Baumdarstellung, Beweisbausteine, Pseudocode-/Entwurfsbausteine oder Graphtrace.
