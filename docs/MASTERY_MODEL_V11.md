# Mastery Model V11

Mastery V11 ergänzt Prim-MST-Dimensionen:

- `prim_startknoten`
- `prim_sichere_kante`
- `prim_key_updates`
- `prim_parent_updates`
- `prim_gesamtgewicht`
- `prim_laufzeit`

Bestehende Mastery-Versionen bleiben unverändert. Die Persistenz speichert weiterhin dimensionsbasierte Records; deshalb war keine IndexedDB-Migration erforderlich.
