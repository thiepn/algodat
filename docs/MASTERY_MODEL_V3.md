# Mastery V3 für Beweise

Mastery V3 speichert Dimensionen für Beweisversuche getrennt von Tracing-Mastery:

- `program_comprehension`
- `mathematical_formulation`
- `proof_structure`
- `formal_reasoning`
- `notation_accuracy`
- `claim_formulation`
- `invariant_formulation`
- `loop_timing`
- `initialization_proof`
- `induction_hypothesis`
- `preservation_proof`
- `termination_reasoning`
- `correctness_conclusion`

Die Werte entstehen ausschließlich aus abgeschlossenen lokalen Versuchen, Punktzahl, Modus, Hinweisen, Lösungsoffenlegung und Fehlercodes. Es werden keine persönlichen Daten extern übertragen.
