# Data Recovery Guide

Alle Daten liegen lokal in IndexedDB. Bei Problemen:

1. Wenn möglich Fortschritt exportieren.
2. Browserdaten nicht vorschnell löschen.
3. Import nur aus vertrauenswürdigen lokalen Exportdateien durchführen.
4. Bei beschädigten Daten den fehlerhaften Bereich isolieren statt alle Stores zu überschreiben.

Es gibt keine Cloud-Sicherung.
