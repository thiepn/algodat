# Final PWA Update Policy

Service-Worker-Updates werden nicht ungefragt aktiviert. Laufende Arbeit soll vor einem Reload gespeichert sein.

Regeln:

- Update anbieten, nicht erzwingen.
- Private PDFs nie precachen.
- Veraltete Caches bereinigen.
- GitHub-Pages-Basispfad beibehalten.
- Offline-Fallback nach vorherigem Laden der App-Shell sicherstellen.
