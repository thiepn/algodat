# Local Data Format Reference

Der lokale Export enthält Datenbankversion, Inhaltsversion, Exportzeitpunkt und validierte Stores:

- `practiceAttempts`
- `masteryRecords`
- `diagnosticSessions`
- `examSessions`
- `examResults`
- `studyPlans`
- `reviewSchedules`
- `cheatSheets`
- `preferences`

`cheatSheets` speichern Auswahl, Varianten, Platzierungen, Quellenzusammenfassung und Druckeinstellungen.
