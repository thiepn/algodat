# Release Bug Classification

## Blocking

Datenverlust, falsche Bewertung, private Quelle im Build, nicht wiederherstellbare Sitzung, unerreichbare Kernroute, kaputter Offline-Start, ungültige Migration, sichtbare Lösung vor Prüfungsabgabe oder kritische Tastaturblockade.

## Major

Falsche Empfehlung, unbrauchbare mobile Kernansicht, erheblicher Fokusfehler, Inkonsistenz zwischen UI und Bewertung oder teilweise fehlerhafter Import/Export.

## Minor

Kosmetik, kleine Textinkonsistenz, nicht kritische Warnung oder sekundäres Performanceproblem.

## Release-Regel

Finaler Release: 0 Blocking, 0 Major. Minor nur dokumentiert und akzeptiert.
