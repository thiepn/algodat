# Mastery Model V9

Mastery V9 ergänzt den Lernstand um Floyd-Warshall-Matrixtracing.

## Dimensionen

- `fw_knotenreihenfolge`
- `fw_initialmatrix`
- `fw_iterationen`
- `fw_rekurrenz`
- `fw_laufzeit`

Die Dimensionen entstehen aus der deterministischen Rubrik des Trainers `trainer-graph-floyd-warshall-v1`. Fachliche Grundlage des Tracingformats: `src-8f16b2505bbd`, Seite 4, und `src-35405e721f05`, Seite 5.
