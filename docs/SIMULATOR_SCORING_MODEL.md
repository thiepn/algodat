# Simulator-Bewertungsmodell

Die Punktzahl wird ausschließlich lokal und deterministisch aus den bestehenden Trainer-Rubriken bestimmt. Die interne Rubrikpunktzahl wird exakt auf die Klausurpunkte des Slots skaliert; Teilergebnisse bleiben erhalten. Die Summe aller Slots beträgt 50 Punkte.

Freitextanteile werden nur als strukturierte Kriterienprüfung ausgewertet. Eine allgemeine semantische Beweisbewertung wird nicht behauptet. Die Ergebnisansicht kennzeichnet die Auswertung ausdrücklich als nicht-offizielle Übungsauswertung.
