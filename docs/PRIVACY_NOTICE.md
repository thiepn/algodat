# Datenschutzhinweis

Das AlgoDat Study System speichert Lernfortschritt lokal im Browser. Es gibt keine Nutzerkonten, keine Telemetrie, kein Backend und keine Cloud-Sicherung.

Wenn du Browserdaten löschst, können Lernstände, Diagnosen, Prüfungssitzungen, Lernpläne und Spickzettel verloren gehen. Exportiere regelmäßig deinen Fortschritt, wenn du ihn sichern möchtest.
