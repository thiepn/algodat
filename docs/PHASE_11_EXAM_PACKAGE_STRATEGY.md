# Phase 11 Prüfungspaket-Strategie

Phase 11 ergänzt einen Adapter `dijkstra_trace` für `trainer-graph-dijkstra-v1`. Der Trainer ist für Aufgabe 3 vorgesehen, weil die reale Dijkstra-Aufgabe in `src-011d1ee23245`, Seite 4, ebenfalls Aufgabe 3 ist.

Die bestehenden Prüfungspakete werden nicht automatisch umgebaut. Der neue Adapter ist verfügbar, ohne alte Slots zu verdrängen. Das verhindert eine stille Änderung bereits validierter Prüfungspakete.
