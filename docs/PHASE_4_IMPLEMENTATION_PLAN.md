# Phase 4 Implementierungsplan

Ziel: genau ein vollständiger vertikaler Beweistrainer für Aufgabe 5.

Umsetzungsschritte:

1. Kandidatengate auf offizielle Quellen.
2. Content- und Rubrik-JSON mit Quellenreferenzen.
3. Reiner Domainkern für Ausdrucksparser, Beweisbewertung, Fehlercodes und Mastery V3.
4. Registry-Erweiterung mit `trainerKind`.
5. Proof-Routen und strukturierter Editor.
6. Persistenzschema Version 4.
7. Unit-, Integrations- und Content-Validierung.
8. Dokumentation und Abschlussbericht.

Vorherige Phase bleibt Voraussetzung: Content- und Phase-Datenvalidierung müssen grün bleiben.
