# Phase 10 Exam Package Strategy

Phase 10 ergänzt genau einen neuen Adapter: `floyd_warshall_matrix`.

## V4-Entscheidung

Es wurde kein `exam-package-kernkompetenz-v4` erstellt.

Begründung: V3 enthält bereits sieben vollständig bewertbare Aufgaben. Ein blindes Anhängen eines weiteren 4-Punkte-Tracings würde das Paket weiter wachsen lassen, ohne ein neues balanciertes 9-Aufgaben-Profil zu erzeugen. Der neue Adapter ist isoliert testbar und kann in einer späteren Phase in ein neu austariertes Paket übernommen werden.
