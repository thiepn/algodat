# Greedy-Design-Linter

## Geprüfte Fehlerklassen

- `greedy_interpretation_error`
- `greedy_rule_error`
- `greedy_algorithm_error`

- `greedy_runtime_error`
- `greedy_memory_error`

## Prinzip

Der Linter normalisiert Leerraum, `·` und `*`, erfindet aber keine semantische Äquivalenz. Wenn eine Eingabe abweicht, wird der erwartete belegte Baustein angezeigt.

## Beleg
