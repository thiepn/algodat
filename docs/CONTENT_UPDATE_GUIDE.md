# Content Update Guide

1. Quelle klassifizieren und Quellenkonflikte dokumentieren.
2. Public-safe Inhalt neu formulieren.
3. JSON gegen Schema anbinden.
4. `npm.cmd run build:content` ausführen.
5. `npm.cmd run validate:content` ausführen.
6. Fachliche Aussagen mit Datei- und Seitenbezug dokumentieren.

Private PDFs in `pdfs/` bleiben unveröffentlicht.
