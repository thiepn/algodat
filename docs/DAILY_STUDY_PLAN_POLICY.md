# Daily Study Plan Policy

Der Tagesplan speichert `inputFingerprint`, Policy-Version, Generierungszeit, Grund, Aktivitäten, geschätzte Gesamtzeit und Abschlussstatus.

Queue-Regeln:

- Tagesbudget wird nicht überschritten.
- Maximal eine breite Diagnose pro Tag.
- Maximal zwei Aktivitäten derselben tiefen Trainerfamilie.
- ExamPackage nur bei ausreichendem Zeitbudget.
- Skip und Snooze verändern keine fachliche Mastery.
- Abschluss muss explizit markiert oder an echte Ergebnis-IDs gebunden werden.

Die UI zeigt maximal drei Aktivitäten prominent; weitere Aktivitäten bleiben einklappbar.
