# Nutzerhandbuch

## Start

Öffne die App lokal oder als PWA. Beginne mit Diagnose, Lernplan oder Trainerübersicht.

## Empfohlener Workflow

1. Schnellcheck starten.
2. Lernplan erzeugen.
3. Einen tiefen Trainer bearbeiten.
4. Wiederholungen erledigen.
5. Probeklausur im Simulator schreiben.
6. Prüfungsreife ansehen.
7. A4-Spickzettel erstellen.
8. Fortschritt exportieren.

## Datenschutz

Alle Daten bleiben auf deinem Gerät. Es gibt keine Cloud-Sicherung.

## Grenzen

Die App ist keine offizielle Notensimulation und bewertet keine beliebigen freien Lösungen.
