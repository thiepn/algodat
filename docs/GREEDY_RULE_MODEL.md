# Greedy-Regelmodell

## Kanonische Regel

Für die Fitnesspunkte-Aufgabe wird `S[1..n]` absteigend sortiert. Größere Schwierigkeitsgrade werden früher eingeplant.

## Beleg

Die Regel stammt aus der Lösungsskizze zu Aufgabe 7: `src-8a588d5ddc35`, Seite 8.

## Bewertete Felder

- Sortierreihenfolge.
- Gleichstandsregel.
- lokale Entscheidung.
- Begründung über die Faktoren `n - i + 1`.

Gleich große Werte dürfen beliebig angeordnet werden; das ändert den Zielfunktionswert nicht.
