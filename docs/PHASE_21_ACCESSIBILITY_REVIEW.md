# Phase 21: Accessibility Review

Die Renderer verwenden beschriftete Eingabefelder, Tabellenköpfe, sichtbare Textstatus und `aria-live` für den Speichervorgang. Graphdaten besitzen eine textuelle Kantenliste; die DP-Tabelle ist semantisch tabellarisch und in ihrem Container scrollbar.

Automatisierte Prüfungen ersetzen keinen Narrator- oder NVDA-Test. Der Screenreader-Gate bleibt daher offen.
