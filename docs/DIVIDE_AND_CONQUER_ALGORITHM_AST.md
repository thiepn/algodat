# Divide-and-Conquer Algorithmus-AST

Phase 13 verwendet einen strukturierten Antwort-AST:

- `interpretation`
- `decomposition`
- `combine`
- `algorithm`
- `recurrence`
- `proof`

Die Felder sind diskriminiert über `kind: "divide_conquer_max_difference"`. Der AST ist absichtlich eng und enthält keine optionalen Universal-Felder.
