# Study Recommendation Explanations

Jede Aktivität kann erklären:

- welche Evidenz sie ausgelöst hat,
- welche Kompetenz betroffen ist,
- welchem Klausurslot sie zugeordnet ist,
- warum sie priorisiert wurde,
- wie lange sie dauert,
- was als Abschluss gilt.

Standardtexte zeigen keine technischen Rohscores. Ein Detailbereich darf Faktoren und Beiträge zeigen. Die UI nutzt Sätze wie „Diese Wiederholung ist heute fällig“ oder „Für diesen Klausurslot fehlt ein Versuch unter Zeitdruck“.
